# DRIVORA – Premium Car Rental Website

DRIVORA is a modern, responsive car rental booking website built using React, Vite, and Tailwind CSS. It provides a premium vehicle browsing experience with car details, rental booking, customer reviews, and booking confirmation.

## 🚗 Project Overview

DRIVORA makes it easy for users to explore different vehicles, compare rental prices, view vehicle specifications, and submit booking requests through a clean and user-friendly interface.

## ✨ Features

### 1. Home Page
- Modern and responsive landing page.
- Premium hero section with automotive visuals.
- Animated website introduction.
- Car search and booking section.
- Featured vehicle collection.
- About DRIVORA section.
- Customer testimonials.
- Smooth scroll animations.

### 2. Car Collection
- Browse multiple vehicles.
- SUVs, luxury cars, sedans, sports cars, electric cars, and hatchbacks.
- Vehicle images and ratings.
- Daily, weekly, and monthly rental prices.
- Availability status.
- Individual car details pages.

### 3. Car Details
- Vehicle image gallery.
- Car specifications.
- Included features.
- Rental pricing information.
- Availability status.
- Book This Car functionality.

### 4. Booking System
- Customer information form.
- Email and phone number fields.
- Pickup and drop-off locations.
- Rental date and time selection.
- Form validation.
- Automatic rental duration calculation.
- Estimated rental price calculation.
- Booking reference generation.

### 5. Booking Confirmation
- Booking request success page.
- Unique booking reference.
- Selected vehicle information.
- Customer details.
- Rental schedule.
- Estimated booking amount.

### 6. Customer Reviews
- Customer profile images.
- Star ratings.
- Vehicle-specific reviews.
- Responsive review cards.
- Hover animations.

### 7. UI & Animations
- Cinematic DRIVORA intro animation.
- Automatic transition to the Home page.
- Scroll reveal animations.
- Smooth scrolling.
- Interactive hover effects.
- Responsive navigation.
- Hidden scrollbar.
- Mobile-friendly layouts.
